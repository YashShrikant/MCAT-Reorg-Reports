# z/OS Catalog Operations Skills (Copilot + VS Code)

This repository contains reusable Copilot skill templates (`skill.md`) for analyzing and managing z/OS Master Catalog and User Catalog issues.

## Skills Included

- Catalog Integrity Check
- Orphan Dataset Detector
- Duplicate Entry Analyzer

## How to Use

1. Open project in VS Code
2. Open any `sample-*.txt`
3. Invoke Copilot:
   > "Use skill <skill name>"

4. Paste real LISTCAT / IDCAMS output

## Output Style

- Short executive summary (2–3 lines)
- Structured findings
- Suggested IDCAMS fix commands
